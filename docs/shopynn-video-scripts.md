# Shopynn video scripts

Use these with an AI / explainer video tool. Prefer **captions on**, CTA wording matching the site: **Get Started Free**.

Demo data tip: Ghana-looking shop name, **GHS**, 4–6 everyday products, one MoMo (or cash) sale ready.

---

## 1) What is Shopynn — animated explainer (~30s)

**Aspect:** 16:9 (site) · also export 9:16 for ads  
**Tone:** Clear, warm, retail-practical — not Silicon Valley hype  
**Style prompt for the tool:** Flat/2.5D motion graphics, Ghana retail setting, laptop + phone UI stylized (not exact screenshots), warm earth tones, clean icons, soft transitions. No tiny unreadable UI text — use simple labels: Stock, Sale, MoMo, Reports.

### Full voiceover (read aloud ~30s)

Running a shop shouldn’t mean guessing what’s in stock or chasing sales in notebooks.

Shopynn is the all-in-one platform for Ghanaian retailers — inventory, in-store sales, orders, and reports in one place.

Track stock in real time. Ring up sales with cash or MoMo. Check today’s numbers on your phone — from anywhere.

One store or many branches. Everything stays in sync.

Start free. Set up your shop in minutes with Shopynn.

3. Thumbnail: cart with **GHS** total or calm modern counter — not a plain logo.  
4. End CTA text must match the website: **Get Started Free**.  
5. Keep stylized UI simple; exact product demos should use a real screen recording (Section 3).
