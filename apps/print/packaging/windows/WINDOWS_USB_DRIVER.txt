Shopynn Print — Windows USB driver (WinUSB / Zadig)
====================================================

Shopynn Print talks to the thermal printer over USB using libusb.
On many Windows PCs the printer is bound to the default USBPRINT driver,
which blocks the print agent. Install WinUSB once with Zadig.

When you need this
------------------
Do this if:
  - Test connection says the agent is OK, but no USB printer is detected, or
  - Printing fails with a USB / access / LIBUSB error.

Steps (one-time per PC / printer)
---------------------------------
1. Plug in the USB thermal printer and power it on.
2. Download Zadig: https://zadig.akeo.ie/
3. Run Zadig as Administrator.
4. Options → List All Devices.
5. Select your thermal printer in the device list
   (not "USB Composite Device" if a more specific printer name exists).
6. In the target driver box, choose WinUSB.
7. Click Install Driver or Replace Driver.
8. Close Zadig.
9. Restart the Shopynn Print Windows service (or reboot the PC).
10. In Shopynn (mobile or web): open Print agent / Invoice & Receipt,
    enter this PC's LAN IP, then Test connection again.

Notes
-----
- You usually only need to do this once per machine.
- After WinUSB is installed, Windows "Devices and Printers" may no longer
  treat the device as a normal Windows printer — that is expected for Shopynn Print.
- Firewall: allow inbound TCP port 3001 if phones print over Wi-Fi.
